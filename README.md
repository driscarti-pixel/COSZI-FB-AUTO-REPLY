# COSZI FB AUTO REPLY — starter dashboard

This is the first Android-friendly dashboard prototype.

## Included
- Responsive violet dashboard
- Auto-reply preview toggle (UI only)
- Default reply text setting
- Adjustable reply-delay preference
- Cooldown preference
- Typing-monitor preference
- Reaction preference selector
- Local activity log

## Important limitations
This starter is **not connected to Facebook** and does not send messages, detect typing, or send reactions. A normal Android Chrome tab does not provide a supported way for a separate website to control Facebook's private UI. The next phase needs a separately installed Android component or an approved integration, plus careful testing and compliance with Facebook's terms. Never put your Facebook password into this dashboard.

## Run locally
Open `index.html` in a browser.

## Deploy dashboard
Upload these files to a GitHub repository and connect the repository to a static-site host. The dashboard is only the UI at this stage.
